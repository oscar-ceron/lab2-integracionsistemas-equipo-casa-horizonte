# Ficha de uso crítico de inteligencia artificial

## 1. Datos generales

**Proyecto:** Casa Horizonte – GUÍA DE LABORATORIO III
**Tecnología:** Laravel 13, PHP, MySQL y Laravel Sanctum
**Herramienta de IA utilizada:** ChatGPT
**Propósito:** Apoyar el desarrollo, revisión, documentación y validación del proyecto.

## 2. Actividades en las que se utilizó IA

| Actividad | Apoyo proporcionado por la IA | Validación realizada |
|---|---|---|
| Desarrollo de funcionalidades | Orientación sobre controladores, modelos, relaciones y recursos de API. | Revisión del código y comprobación de su funcionamiento en el proyecto. |
| Autenticación y seguridad | Explicaciones sobre autenticación, tokens y aislamiento de información por usuario. | Revisión de rutas, controladores y pruebas automatizadas. |
| Identificación de errores | Ayuda para interpretar mensajes de error y proponer posibles soluciones. | Ejecución de comandos y pruebas para comprobar cada corrección. |
| Documentación técnica | Apoyo para organizar y redactar la documentación del proyecto. | Comparación del contenido con los archivos y funcionalidades existentes. |
| Pruebas del sistema | Orientación para interpretar resultados y verificar escenarios de funcionamiento. | Ejecución de pruebas con Laravel y revisión de sus resultados. |

## 3. Ejemplos de instrucciones utilizadas

Las siguientes son instrucciones representativas del tipo de consultas realizadas durante el desarrollo:

- Explicar cómo implementar recursos API en Laravel para habitaciones y reservaciones.
- Revisar cómo restringir las reservas para que cada usuario autenticado acceda únicamente a sus propios registros.
- Orientar la implementación de autenticación API mediante Laravel Sanctum.
- Ayudar a interpretar errores de ejecución y resultados de pruebas automatizadas.
- Revisar la documentación técnica y proponer mejoras de organización y claridad.

## 4. Evaluación crítica del uso de IA

**Beneficios identificados:**

- Facilitó la comprensión de conceptos y herramientas de Laravel.
- Permitió identificar posibles errores y alternativas de solución.
- Ayudó a organizar las actividades de desarrollo y documentación.
- Proporcionó orientación para mejorar la estructura del código y las pruebas.

**Limitaciones y riesgos:**

- Las respuestas pueden contener errores o sugerencias que no se ajusten a la estructura del proyecto.
- El código propuesto por una herramienta de IA no debe incorporarse sin revisión.
- Las recomendaciones de seguridad deben comprobarse mediante la revisión del código y pruebas.
- La IA no sustituye el criterio técnico ni la responsabilidad del equipo.

## 5. Criterios de verificación

Para utilizar responsablemente las recomendaciones de IA se consideraron los siguientes criterios:

1. Revisar las sugerencias antes de aplicarlas.
2. Comprobar que los cambios sean compatibles con Laravel y con la estructura del proyecto.
3. Ejecutar pruebas automatizadas después de realizar modificaciones.
4. Verificar que las funcionalidades respeten los permisos y la privacidad de los usuarios.
5. Mantener el control de versiones mediante Git.

## 6. Reflexión final

La inteligencia artificial fue utilizada como una herramienta de apoyo durante el desarrollo del proyecto Casa Horizonte. Permitió facilitar la comprensión de conceptos, analizar errores, organizar soluciones y mejorar la documentación.

Sin embargo, sus respuestas no se consideraron correctas automáticamente. Las recomendaciones debieron revisarse y contrastarse con el código, las pruebas y los requerimientos del proyecto.

El uso responsable de la IA requiere supervisión humana, pensamiento crítico y validación técnica de los resultados.
